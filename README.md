# Пилот: независимые ячейки против числа сегментов

Проверяется гипотеза 1 из исходного документа: при одинаковом числе обучающих сегментов прогноз ресурса улучшается, если сегменты взяты от большего числа независимых физических ячеек.

Запуск: `python run_pilot.py`. Скрипт скачивает открытые обработанные признаки Severson (разбиение train и независимый test1) в `data/`, обучает Random Forest и сохраняет метрики в `results.json`. Данные не включены в Git; источник и лицензия описаны в `FST_EXP.md`.

Подробности дизайна, численный итог и ограничения: [FST_EXP.md](FST_EXP.md).
